# Review Test Gaps

Compare a SPEC, o diff e a suíte. Para cada RF/RNF afetado, reporte cobertura de:
- happy path;
- entradas inválidas;
- limites/boundaries;
- invariantes;
- regressões relevantes.

Não gere requisito novo. Não considere cobertura de linhas como substituta de cobertura de requisito.
