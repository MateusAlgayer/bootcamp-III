# Review Pull Request

1. Leia `AGENTS.md`, a SPEC e os ADRs aplicáveis.
2. Identifique os RF/RNF afetados pelo diff.
3. Verifique implementação, testes e mudanças de contrato.
4. Classifique achados como `BLOCKER`, `HIGH`, `MEDIUM`, `LOW` ou `INFO`.
5. Para cada achado, informe requisito, arquivo e justificativa.
6. Não altere código e não invente comportamento ausente na SPEC.
